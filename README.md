# ✍️ Hand-Written Articles

> Learn it. Understand it. Write it in my own words.
I learn a new topic, I write an article about it here. 


## 💡 Why This Repo Exists

If I can explain a topic simply, I truly understand it. 
If I can't, I know I need to learn more. 
Writing is how I test myself.


## 🤝 Feedback Welcome

I'm still learning, so I will make mistakes. 
Found one? Open an issue or a pull request. Corrections make me better.
